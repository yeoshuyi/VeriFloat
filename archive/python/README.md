# verifloat_py (frozen)

The original pure-Python implementation of VeriFloat 0.1, frozen at git tag
`python-v0.1.0`. Do not modify it: it is the reference oracle that
`tests/test_parity.py` checks the C++-backed `verifloat` package against.
The code is unchanged apart from the package rename (`verifloat` -> `verifloat_py`).
